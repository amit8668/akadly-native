Remote Access

A real Linux terminal and/or full graphical desktop on a Raspberry Pi (or any Linux box) — not the MicroPython REPL. Both need something running on the target machine first; see the setup notes below.

1. Terminal

The address ttyd is listening on for the target machine.

2. Desktop (VNC)

The address a noVNC/websockify bridge is listening on for the target machine (points at vnc.html, not the raw VNC port).

Both open in their own browser tab, not embedded here.
Akadly is HTTPS; a home-network terminal or desktop bridge is normally plain HTTP, and browsers silently refuse to embed HTTP content inside an HTTPS page's iframe (mixed-content blocking) — there's no reliable way around that short of putting a real TLS certificate on the target machine. A new tab has no such restriction, so that's what these buttons do. Strongly recommended either way: put the target machine on the same private network as this browser (e.g. Tailscale) instead of exposing either port to the open internet. See the setup guide for exact steps.
